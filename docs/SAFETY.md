# Safety

本项目是实验室工作流，不是经过认证的机器人安全系统。软件限制、loopback 网络边界和页面中的
Stop 都不能替代机械固定、人员隔离和独立断电。

## 操作等级

| 等级 | 示例 | 主要要求 |
|---|---|---|
| A：只读软件 | 文档、测试、Browse、离线审计 | 不构造真实设备，不修改原始数据 |
| B：相机观察 | 预览、分辨率/帧率确认 | 保护隐私，单一进程占用，离开前释放句柄 |
| C：设备配置 | Connect、校准、setup motors | 有人现场，确认供电与身份，先备份现有配置 |
| D：受控运动 | Teleoperate、Record、Replay、Inference | 固定、净空、小范围、正常停止和独立断电均可用 |
| E：异常恢复 | 超时、失控、突跳、通信故障 | 停止发送，不盲目重试，先隔离能量再诊断 |

从 A/B 进入 C/D 前必须有当次现场条件；USB 已连接不是进入运动等级的授权。

## Stop 的边界

UI Stop 表示请求当前软件任务停止。它不承诺：

- 电机立即失能；
- 网络或串口中已发送的目标被撤销；
- 浏览器卡死时仍可工作；
- 达到 emergency-stop 或功能安全等级。

真实运动时始终准备一个不依赖浏览器、键盘焦点或同一进程的独立停止/断电方法。

## 运动规则

- 只允许现场操作者移动 leader；不生成随机动作。
- 不在无人值守状态运行 Teleoperate、Record、Replay 或 Inference。
- 不未经确认改 firmware、motor ID、baud 或校准。
- 不把通信 timeout 当作“动作没有发生”，也不盲目重发。
- 换模式、故障重连或姿态未知后重新检查工作区。
- `max_relative_target` 是目标差限制，不是速度、碰撞、力矩或人机协作认证。

## 网络边界

服务只应绑定 `127.0.0.1`。运行时拒绝非可信 Host、Origin 与 WebSocket 来源。不要通过端口转发、
反向代理或公开隧道把本地控制页面暴露到网络；如需远程控制，必须先单独设计并评审安全边界。

## 数据与隐私

- wrist/front 画面可能包含家庭环境、人员和屏幕内容。
- 原始视频、Parquet、校准、串口标识、日志、模型和凭据默认留在本机。
- `push_to_hub`、云训练和外部实验跟踪默认关闭。
- 浏览或审计不能隐式 repair/delete 原始数据。
- 删除数据、上传数据与公开代码是三个独立操作，不能由一个普通按钮连带完成。

任何截图或问题报告都应先去除设备序列号、用户名、绝对路径、家庭画面与账户信息。
